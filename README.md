# Asteroids

A 2D Asteroids clone built with Python and Pygame, following boot.dev's ***Build Asteroids using Python and Pygame*** course

## Requirements

- Python 3.12+
- [uv](https://docs.astral.sh/uv/)

## How to Run

1. Clone the repository:
   ```bash
   git clone <repo-url>
   cd asteroids
   ```

2. Run the game:
   ```bash
   uv run main.py
   ```
